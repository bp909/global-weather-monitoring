# Global Weather Monitoring
## Introduction
This project sought to obtain a cloud free image, and use that image to analyse weather patterns on the earth. Whilst a project conducted in partnership, we wrote different code and analysed different patterns. I analysed the vegetation coverage over the African Continent. The final report is included in these compiled files, which includes fully my methodology.
For this zip file submission, I have gone through the files to find the files used for my final analysis, and commented the relevant parts. I have omitted the resource files as they are approximately 16 years worth of daily images from 3 (Red, Green, and Blue) channels.
## Code Used
The code used is a smattering of both MATLab (for analysis) and Python (for graphing), is mostly scripts, and was not well commented at the time.
