# Global Weather Monitoring
This project sought to obtain a cloud free image, and use that image to analyse the vegetation coverage on the African continent. Whilst this project conducted somewhat in partnership, we wrote different code and analysed different patterns (they concentrated on the cloud). The final report is included in these compiled files, which includes fully my methodology.
For this submission, I have gone through the files to find the files used for my analysis, and commented the relevant parts. I have omitted the resource files as they are approximately 16 years worth of daily images from 3 (Red, Green, and Blue) channels.

I have gone through and commented the code files at the top to explain their function. Some of these may not be the best explanations, and it has been 6 years since this was written and used, so my memory may be erroneous.
## Code Used
The code used is a smattering of both MATLab (for analysis) and Python (for graphing), is mostly scripts, and was not well commented at the time.
